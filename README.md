 # School Companion — Frontend

This repository contains the frontend application (Vite + React) extracted from the School-Companion-AI monorepo.

Contents
- `src/` — React source files
- `public/` — Static assets

How to run

1. Install dependencies:

```powershell
cd frontend
npm install
```

2. Run dev server:

```powershell
npm run dev
```

Notes
- Environment variables are stored in `.env*` files and are ignored by this repo's `.gitignore`.
- Create a GitHub repo and add it as the remote, then push with `git push -u origin main`.
